# 🌲 3D Forest Explorer

### Explore. Relax. Enjoy Nature.

A beautiful interactive 3D forest experience built using **HTML5, CSS3, JavaScript, and Three.js**. Explore a virtual forest with 3D trees, rocks, glowing fireflies, atmospheric lighting, and a forest photo background.

## ✨ Features

- 🌳 **3D Forest Environment** — Procedurally generated trees and rocks.
- 🏞️ **Forest Photo Background** — A forest image enhances the natural scenery.
- ☀️ **Dynamic Lighting Modes** — Switch between sunny day, sunset, and night.
- ✨ **Animated Fireflies** — Glowing particles float around the forest.
- 🌫️ **Atmospheric Fog** — Adds depth to the forest environment.
- 🖱️ **Interactive Camera** — Move your mouse to look around.
- 📱 **Responsive Design** — A user interface adapted for different screen sizes.
- 🎮 **Keyboard Controls** — Use keyboard shortcuts to change lighting and reset the view.

## 🚀 How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/3d-forest-explorer.git
   ```

2. Open the project folder in Visual Studio Code.

3. Add your forest image as `images/forest.jpg`.

4. Install the **Live Server** extension in VS Code.

5. Right-click `index.html` and select **Open with Live Server**.

6. Explore the forest in your browser.

**Requirements:** An internet connection is needed to load Three.js from its CDN.

## 🎮 Controls

| Control | Action |
|---|---|
| Mouse movement | Look around |
| Environment selector | Change lighting mode |
| `1` | Sunny day |
| `2` | Sunset |
| `3` | Night |
| `R` | Reset camera |
